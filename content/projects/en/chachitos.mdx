## Context

Chachitos is a Mexican company that has been making puffed-wheat cereal for over
70 years. The project is its official website: a modern, fast, responsive
presence.

## Architecture

A Next.js site on the App Router, organized into clear routes (Home, About,
Flavors, Menu, Find Us):

- `components/` — reusable components, including the Google Maps integration and
  the store locator.
- `const/` — company constants (values, addresses, social links).
- `mocks/` — sample data (products and flavors).
- `utils/` — helpers such as distance calculation with the Haversine formula.

## Stack

- Next.js 15 + React 19 + Tailwind CSS + TypeScript.
- Google Maps API for the store locator, with marker clustering.
- reCAPTCHA and Resend for the contact forms.
- scrollreveal for entrance animations.

## Outcome

An institutional site with a working store locator that computes the distance
from the visitor to each point of sale.
